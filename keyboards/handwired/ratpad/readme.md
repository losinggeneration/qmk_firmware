# RatPad

A 42-key ergonomic game keypad made by losinggeneration

* Keyboard Maintainer: [losinggeneration](https://github.com/losinggeneration)
* Hardware Supported: Elite-Pi
* Hardware Availability: [losinggeneration](https://github.com/losinggeneration/ratpad)

Make example for this keyboard (after setting up your build environment):

    make handwired/ratpad:default

See [build environment setup](https://docs.qmk.fm/#/getting_started_build_tools) then the [make instructions](https://docs.qmk.fm/#/getting_started_make_guide) for more information.
